# контекст:
Изучи документацию к проекту - README.md в корне решения. Если необходимо исследуй файлы, в том числе dev-notes.md.
В настоящий момент приложение представляет одну страницу, в которой после собеседования можно посмотреть итоговый отчёт на служебной странице
Но претендентов на должность может быть много. Должна быть возможность просматривать всех кандидатов, фильтровать их.

# цель:
- Необходимо в базу данных добавить таблицу с кандидатами candidates, связанную по ключу с таблицей interviews. Один кандидат - одно интервью
таблица candidates имеет следующие поля:
id - guid
name - строковое
email - строковое
phone_number - строковое (могут быть +)
role - строковое
experiance - строковое
created_at (timestamptz)
updated_at (timestamptz)
resume - текстовое
hiring-recommendation - строковое

- на главной в форме после ниспадающего списка должностей "Выберите должность, на которую претендуете" добавить элементы пользовательского интерфейса для ввода имени претендента,
 его email, номера телефона и опыта(experiance).
 Все поля должны проходить валидацию. Формат для номера телефона следующий: +7-903-945-00-88
 Эти поля ввода должны появляться только после того, как пользователь выберет должность.
 Кнопка «Начать собеседование» неактивна, пока все поля пользователь не заполнит.
 - Данная информация должна записаться в таблицу candidates после того, как пользователь нажмёт «Начать собеседование»
 - поля: role, created_at - должны заполниться автоматически. Данные мы знаем
 - Поля: resume, hiring-recommendation пока не заполняем
 - На служебной странице сначала нужно отображать таблицу из кандидатов. Отображаются следующие поля: name, email, phone_number, role, experience и hiring-recommendation
 - Также на служебной странице нужно добавить фильтр по должностям (role) и по hiring-recommendation
 - Имена столбцов должны быть на русском языке
 - Финальный отчёт формируется после того, как собеседование завершено. Точно так же, как и в данный момент
 - Финальный отчёт должен отображаться после того, как пользователь выберет кандидата на служебной странице
 - Из финального отчёта взять поле hiringRecommendation, если оно есть и его содержимое вставить в соответствующее поле таблицы candidates
